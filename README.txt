DATKA HOTEL — сайт отеля «Датка», Ош

Состав:
  index.html        — весь сайт (HTML, CSS и JavaScript в одном файле)
  img/              — оптимизированные фотографии (WebP)

Как запустить:
  1. Откройте index.html двойным щелчком — сайт работает в браузере без установки.
  2. Для публикации загрузите папку целиком на любой хостинг
     (Netlify, GitHub Pages, обычный хостинг через FTP). Сборка не нужна.

Как подключить WhatsApp и телефон:
  Откройте index.html в текстовом редакторе, найдите блок «НАСТРОЙКИ» и впишите:
    const WHATSAPP_NUMBER = "996XXXXXXXXX";   // только цифры, без +, пробелов и скобок
    const CONTACT_PHONE   = "+996 XXX XXX XXX";
  Пока номер пуст, кнопка WhatsApp не ведёт в пустоту: сайт показывает текст заявки
  и предлагает его скопировать.

Как заменить фотографии:
  Положите новые файлы в img/ под теми же именами
  (hotel-exterior.webp, room-classic.webp, room-twin.webp)
  или поправьте пути в блоке const IMG в index.html.
